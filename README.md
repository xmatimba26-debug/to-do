# To-Do List App

A clean and user-friendly To-Do List application built with **React** and **SCSS** to help users organize tasks, manage priorities, and track their progress.

## Features

- Add new tasks
- Organize tasks by category and priority
- Set task dates and due dates
- Mark tasks as completed
- Delete individual tasks
- Track completed, pending, and in-progress tasks
- View task statistics
- Responsive and modern user interface

## Built With

- React
- JavaScript
- SCSS
- HTML5
- CSS3

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate into the project directory:

   ```bash
   cd to-do
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```
